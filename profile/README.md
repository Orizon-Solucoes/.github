## Sobre a Orizon

A **Orizon Soluções** é uma iniciativa voltada ao desenvolvimento de soluções em tecnologia, oferecendo serviços e ferramentas para atender às necessidades de empresas e profissionais.

Nosso objetivo é simplificar processos, melhorar a infraestrutura tecnológica e desenvolver soluções digitais que contribuam para o crescimento dos negócios.

## Áreas de atuação

| Área | Soluções |
|---|---|
| Desenvolvimento | Websites, sistemas e aplicações personalizadas. |
| Suporte técnico | Manutenção, diagnóstico e configuração de equipamentos. |
| Redes e infraestrutura | Redes locais, cabeamento, roteadores, switches e pontos de acesso. |
| Segurança eletrônica | Instalação e manutenção de sistemas de CFTV. |
| Automação | Ferramentas digitais para otimização de processos empresariais. |

## Projetos

Conheça alguns dos projetos desenvolvidos e mantidos pela Orizon:

### Chromebook Manager
Sistema web para gerenciamento de equipamentos de TI, inventário, manutenções e acompanhamento de custos em ambientes escolares.

### Gerador de Código de Barras
Aplicativo desktop para cadastro de produtos, geração de códigos de barras e impressão de etiquetas.

### Gestão Oliveira
Sistema desktop voltado ao gerenciamento de vendas, estoque e controle de caixa.

### Website Orizon
Website institucional desenvolvido para apresentar a empresa, seus serviços e suas soluções tecnológicas.

## Tecnologias

Trabalhamos com tecnologias e ferramentas voltadas ao desenvolvimento de aplicações, infraestrutura e gestão de ambientes tecnológicos.

- **Desenvolvimento:** JavaScript, TypeScript, React, Next.js e Python.
- **Banco de dados:** MySQL e SQLite.
- **Infraestrutura:** Redes TCP/IP, cabeamento estruturado, roteadores e switches.
- **Ferramentas:** Git, GitHub, VS Code e Vercel.

## Nosso compromisso

Buscamos desenvolver soluções funcionais, confiáveis e acessíveis, priorizando qualidade, organização e evolução contínua.

Cada projeto é desenvolvido com foco nas necessidades reais de quem utiliza a tecnologia no dia a dia.
